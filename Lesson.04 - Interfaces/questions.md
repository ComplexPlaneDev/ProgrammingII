### 1. What is a Java interface?

A. A class that cannot contain methods
B A package of related classes
C A reference type that specifies a set of methods a class must mplement

**Correct answer:** C

------------------------------------------------------------------------

### 2. Which keyword is used when a class adopts an interface?

A. extends
B. implements
C. inherits

**Correct answer:** B

------------------------------------------------------------------------

### 3. Can a class implement multiple interfaces?

A. Yes
B. No
C. Only two

**Correct answer:** A

------------------------------------------------------------------------

### 4. Can an interface extend another interface?

A. No
B. Yes
C. Only if it has no methods

**Correct answer:** B

------------------------------------------------------------------------

### 5. What is the main purpose of interfaces?

A. Improve runtime speed
B. Define a contract that classes must follow
C. Replace constructors

**Correct answer:** B

------------------------------------------------------------------------

### 6. What happens if a class implements an interface but does not implement all its methods?

A. Compile error
B. Runtime exception
C. Java inserts empty implementations

**Correct answer:** A

------------------------------------------------------------------------

### 7. What must a class be if it does not implement all interface methods?

A. final
B. static
C. abstract

**Correct answer:** C

------------------------------------------------------------------------

### 8. What type can reference an object implementing an interface?

A. Only the concrete class
B. The interface type
C. Only Object

**Correct answer:** B
