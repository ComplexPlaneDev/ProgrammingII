### 1. What does the `new` keyword do in Java?

A. Allocates memory for an object and calls its constructor
B. Declares a new class
C. Copies an existing object

**Correct answer:** A

------------------------------------------------------------------------

### 2. What is stored in a Java object variable?

A. The object itself
B. A reference to the object
C. The constructor code

**Correct answer:** B

------------------------------------------------------------------------

### 3. What happens if you declare a field in a class but do not initialize it?

A. It gets a default value
B. It contains a random value
C. The program does not compile

**Correct answer:** A

------------------------------------------------------------------------

### 4. What is the main purpose of a constructor?

A. Destroy objects
B. Declare fields of the class
C. Initialize objects when they are created

**Correct answer:** C

------------------------------------------------------------------------

### 5. What does the `static` keyword mean for a field?

A. Each object has its own copy
B. The field cannot be modified
C. The field belongs to the class

**Correct answer:** C

------------------------------------------------------------------------

### 6. Which keyword allows one constructor to call another constructor in the same class?

A. `super`
B. `this`
C. `static`

**Correct answer:** B

------------------------------------------------------------------------

### 7. What is the default visibility if no access modifier is specified?

A. public
B. private
C. package-private

**Correct answer:** C

------------------------------------------------------------------------

### 8. What is the purpose of a Java package?

A. Compress Java classes
B. Organize classes into namespaces
C. Improve execution speed

**Correct answer:** B

------------------------------------------------------------------------

### 9. When is a `static` field initialized?

A. Every time an object is created
B. When the class is first loaded
C. When the program terminates

**Correct answer:** B

------------------------------------------------------------------------

### 10. Which of the following is true about constructors?

A. They have the same name as the class
B. They always return `void`
C. They can be inherited

**Correct answer:** A

------------------------------------------------------------------------

### 11. What happens if a class defines no constructors?

A. The program fails to compile
B. Objects of the class cannot be created
C. Java automatically provides a default constructor

**Correct answer:** C

------------------------------------------------------------------------

### 12. What happens if two classes in different packages have the same name?

A. The program fails to compile
B. They must be referenced using fully qualified names
C. Java automatically renames one

**Correct answer:** B

------------------------------------------------------------------------

### 13. What happens when a static method accesses instance fields?

A. It works normally
B. It causes a runtime error
C. It is not allowed without an object reference

**Correct answer:** C

------------------------------------------------------------------------

### 14. What happens if two constructors have the same parameter types?

A. The second overrides the first
B. The program fails to compile
C. Java chooses one randomly

**Correct answer:** B

------------------------------------------------------------------------

### 15. What is the purpose of `this` inside a method?

A. Refer to the current object
B. Refer to the parent class
C. Create a new object

**Correct answer:** A
