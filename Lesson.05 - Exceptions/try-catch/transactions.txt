# Bank Transaction Processor – Input File
# Format: COMMAND ACCOUNT AMOUNT  or  TRANSFER FROM TO AMOUNT
# Lines starting with # are comments.

WITHDRAW ACC002 200.00

# ACC999 does not exist
TRANSFER ACC001 ACC999 100.00
