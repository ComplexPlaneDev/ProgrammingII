### 1. What is an exception in Java?

A. A syntax error detected by the compiler
B. A special type of variable
C. An event that disrupts the normal flow of program execution

**Correct answer:** C

------------------------------------------------------------------------

### 2. Which keyword is used to handle exceptions?

A. catch
B. handle
C. intercept

**Correct answer:** A

------------------------------------------------------------------------

### 3. Which keyword is used to raise an exception explicitly?

A. throw
B. raise
C. emit

**Correct answer:** A

------------------------------------------------------------------------

### 4. Which keyword declares that a method may throw exceptions?

A. throw
B. throws
C. exception

**Correct answer:** B

------------------------------------------------------------------------

### 5. Which block always executes whether an exception occurs or not?

A. catch
B. finally
C. throws

**Correct answer:** B

------------------------------------------------------------------------

### 6. Which class is the root of the exception hierarchy?

A. Exception
B. Throwable
C. Error

**Correct answer:** B

------------------------------------------------------------------------

### 7. Which category represents recoverable conditions in Java?

A. Errors
B. Exceptions
C. Threads

**Correct answer:** B

------------------------------------------------------------------------

### 8. What happens if an exception is not caught?

A. The JVM ignores it
B. The compiler fixes it
C. The program terminates after stack unwinding

**Correct answer:** C

------------------------------------------------------------------------

### 9. Can a try block exist without a catch block?

A. Yes, if it has a finally block
B. No
C. Only in static methods

**Correct answer:** A

------------------------------------------------------------------------

### 10. What is a checked exception?

A. An exception checked by the compiler
B. An exception checked at runtime
C. An exception handled automatically

**Correct answer:** A

------------------------------------------------------------------------

### 11. What is an unchecked exception?

A. An exception detected by static analysis
B. An exception that must always be caught
C. An exception that extends RuntimeException

**Correct answer:** C

------------------------------------------------------------------------

### 12. What happens if a method throws a checked exception but does not declare it?

A. Runtime exception
B. Compile error
C. JVM warning only

**Correct answer:** B

------------------------------------------------------------------------

### 13. What is stack unwinding?

A. Propagating an exception up the call stack
B. JVM allocating memory
C. Destroying objects manually

**Correct answer:** A

------------------------------------------------------------------------

### 14. What happens if multiple catch blocks match an exception?

A. All are executed
B. Only the first matching one executes
C. The JVM chooses randomly

**Correct answer:** B

------------------------------------------------------------------------

### 15. What is the purpose of custom exceptions?

A. Represent domain‑specific error conditions
B. Improve CPU performance
C. Replace interfaces

**Correct answer:** A
