### 1. What is inheritance in Java?

A. The ability to copy objects
B. The ability for a class to acquire properties and methods from another class
C. The ability to overload methods

**Correct answer:** B

------------------------------------------------------------------------

### 2. Which keyword is used to inherit from a class in Java?

A. implements
B. inherits
C. extends

**Correct answer:** C

------------------------------------------------------------------------

### 3. What is the class being inherited from called?

A. Parent class / superclass
B. Child class
C. Instance class

**Correct answer:** A

------------------------------------------------------------------------

### 4. What is the class that inherits called?

A. Parent class
B. Subclass / child class
C. Root class

**Correct answer:** B

------------------------------------------------------------------------

### 5. Which class is the root of the Java class hierarchy?

A. Base
B. Object
C. Class

**Correct answer:** B

------------------------------------------------------------------------

### 6. What keyword is used to call a superclass constructor?

A. super
B. parent
C. base

**Correct answer:** A

------------------------------------------------------------------------

### 7. What does method overriding mean?

A. Copying a method from another class
B. Creating multiple methods with different parameters
C. Defining a method in a subclass with the same signature as in the superclass

**Correct answer:** C

------------------------------------------------------------------------

### 8. What happens if a subclass does not define a constructor?

A. The program fails to compile
B. The superclass constructor is automatically called
C. No constructor is executed

**Correct answer:** B

------------------------------------------------------------------------

### 9. What visibility allows subclasses to access a field directly?

A. private
B. protected
C. static

**Correct answer:** B

------------------------------------------------------------------------

### 10. Can a subclass access private fields of its superclass?

A. No
B. Yes
C. Only if static

**Correct answer:** A

------------------------------------------------------------------------

### 11. What is dynamic binding?

A. Methods are chosen at runtime based on the object's actual type
B. Methods are chosen at compile time
C. Methods are always static

**Correct answer:** A

------------------------------------------------------------------------

### 12. What happens when a superclass reference points to a subclass object?

A. Only superclass methods exist
B. The object becomes the superclass type
C. Dynamic method dispatch occurs

**Correct answer:** C

------------------------------------------------------------------------

### 13. Which methods cannot be overridden?

A. private methods
B. static methods
C. both of the above

**Correct answer:** C

------------------------------------------------------------------------

### 14. What is polymorphism?

A. One object having multiple references
B. Creating multiple constructors
C. The ability to treat subclass objects as superclass types

**Correct answer:** C

------------------------------------------------------------------------

### 15. What happens if a superclass constructor requires parameters and the subclass has no constructor?

A. Java inserts `super()` automatically
B. Compile error
C. Runtime exception

**Correct answer:** B
