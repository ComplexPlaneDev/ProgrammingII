# Set 1 – Basic Questions

### 1. What is linear search?
A. Search in sorted array only  
B. Sequential search through elements  
C. Binary splitting  

**Correct answer:** B

---

### 2. What is binary search?
A. Sequential search  
B. Divide-and-conquer search on sorted data  
C. Hash-based search  

**Correct answer:** B

---

### 3. What is required for binary search?
A. Unsorted array  
B. Sorted array  
C. Linked list  

**Correct answer:** B

---

### 4. What is the time complexity of linear search?

B. O(log n)

### 8. Which is a comparison-based sort?

### 9. What is a stable sort?

### 10. What is an in-place sort?
